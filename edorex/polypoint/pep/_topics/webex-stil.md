# Webex-Stil (Selina, PEP)

Aus dem PEP-Index ausgelagert am 2026-11-26 (Index-Health M009), Wortlaut unverändert.

- **Webex-Kanal «UX PDX Design System»** (Karin, Zoltan, Luca, Selina): Tonfall locker-kollegial, Du, «Hallo & guten Morgen zusammen!», kurz begründen, Optionen nummeriert mit «Meinung:»-Zeile, Bilder als Reihen (1. Reihe aktuell / 2. Reihe Vorschlag). Entwürfe für Selina in diesem Stil schreiben.
- **✍️ WEBEX-STILVORLAGE «Info + Optionen» (Selina 20.10.2026, Snackbar-Icons, so gesendet):** Einstieg «Hello zusammen!» + Kontextsatz («Bin gerade die Snackbar am Fertig machen.») + Ankündigung («Hier gerne kurz eine Info + 2 Optionen inkl. einer Empfehlung:») · Block **«Info:»** als Aufzählung (Befund, Abweichung, Beobachtung Storybook mit vorsichtiger Vermutung + Emoji 🤔?) · Zahlen/Belege als eigene Unterliste · **«Daher folgende 2 Optionen:»** mit «1. Option:» / «2. Option» je eigener Zeile · Ton locker, Du, kurz. Entwürfe künftig in dieser Struktur liefern.
- **✍️ «(zu 99%✌️)» NICHT MEHR VERWENDEN (Selina 9.11.2026):** nutzt sich ab → in Fertigmeldungen weglassen.
- **✍️ WEBEX «FERTIG»-MELDUNG — STIL (Selina 22.10.2026, Snackbar, so gesendet):** Kürzer als mein Entwurf: nur **2 Kernpunkte** (was ist neu fürs Team/DEV), keine Aufzählung von Variablen/Breite/Doku/Nebenthemen (Icon-Bug weggelassen). Aufbau: «ℹ️ Zur Info: <Komponente> ist fertig» (ggf. Augenzwinkern «(zu 99%✌️)») · 2 Bullets · Block **«Wichtig:»** für Offenes (offene Frage + «Sobald … geklärt und Doku nachgeführt, ist die <Komponente> dev. fertig.») · Schluss **«Wie erwähnt, müsste SB noch nachgeführt werden:»** + Bullets (SB = Storybook). Entwürfe künftig so knapp liefern.
- **📣 FERTIG ⇒ AKTIV KOMMUNIZIEREN (Selina 8.10.2026):** Sobald eine Komponente fertig ist (Voll-Audit 0 Befunde + Doku nachgeführt), Selina **daran erinnern, es im Webex «UX PDX Design System» zu melden, und gleich einen Textvorschlag liefern** (ihr Stil: «Zur Info, neu fix-fertig: … alles neu verdrahtet (Farbrampen, Border, Spacing … an Variablen), Doku nachgeführt»; kurz, Aufzählung der Komponenten, ggf. Nebenthema mit «—» abgetrennt). **Format seit 8.10.: Meldung beginnt mit «ℹ️ Zur Info: <Komponente> ist/sind fertig», darunter Stichworte, DEV-Hinweis knapp («In Storybook müsste das noch angepasst werden»).** Erste Meldung so gesendet 8.10.: Buttons + Icon Buttons (+ Scrollbar-Info: alte Version ersetzen, löschen oder archivieren — später, nicht Prio).
