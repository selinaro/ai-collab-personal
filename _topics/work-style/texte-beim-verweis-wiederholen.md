# Texte beim Verweis wiederholen

Verweise ich auf einen Text, den ich früher in der Session geliefert habe (Description, Doku-Zeile, Nachricht), **den Text nochmals vollständig mitliefern**, nie nur «die Texte vom Nachmittag».

**Why:** Selina, 2026-11-03 (PEP, Set-Descriptions Avatar): «gerne das nächste Mal nochmals wiederholen. Sonst muss ich sie suchen gehen oder in Obsidian erfassen.»

**How to apply:** Jede To-do-Zeile, die einen Text braucht, enthält den Text als kopierbaren Block.
